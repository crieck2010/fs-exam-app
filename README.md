# fs-exam-app

**Quiz practice for the NCEES FS exam — iOS and Android. Phase 2 of the FS Exam Prep program.**

Pick your sections (any combination of the 7 FS knowledge areas), set the
question count, and take a quiz. Every question is multiple choice, dynamically
generated by the [`fs-exam-prep`](https://github.com/crieck2010/fs-exam-prep)
engine, with worked explanations on every answer. Light and dark mode included.

## Features

- **Section picker** — all 7 FS domains, multi-select, with per-domain
  question counts and exam weights
- **Dynamic questions** — 480-question banks per seed, generated by the
  versioned engine; new seeds = fresh exams (`tools/generate_banks.py`)
- **Study-grade feedback** — answers lock on first tap (exam discipline),
  explanations reveal immediately (study value)
- **Study system** — question of the day (same for everyone, daily),
  streaks with best-day tracking, and SM-2 spaced repetition with
  **confidence-graded reviews** (Guessed / Pretty sure / Knew it maps to
  the full 0–5 quality scale): every answer schedules the question's next
  review, and the "due for review" queue serves the most overdue first
- **Weekly report + focus areas** — accuracy by section, weakest/strongest
  sections (min 5 attempts to qualify), one-tap drills of failed questions
- **Notification nudges** — QOTD morning nudge, conditional streak saver,
  Monday weekly report; per-nudge toggles in Settings
- **Milestone celebrations** — 7/30/100-day streaks, 100/500/1000 lifetime
  questions, each celebrated once
- **Exam countdown** — optional exam date with phased study advice; weak-area
  pings in the final 30 days (in-app card + smarter notification body)
- **Results** — score, per-section breakdown, expandable miss review,
  retake and drill-your-misses modes (SRS keeps learning through retakes)
- **Light / dark / system theme** — Material 3, persisted across launches
- **Contract-validated banks** — every bank is validated against engine
  schema v1 on load; corrupt banks fail loudly, never silently misgrade

## Architecture

Thin UI over versioned JSON banks — the engine stays in Python:

```
fs-exam-prep engine --(tools/generate_banks.py)--> assets/banks/*.json
        domain picker --> filter + shuffle --> QuizController --> ResultsScreen
```

Full details: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) ·
[docs/CONTRACT.md](docs/CONTRACT.md) (engine schema v1 mapping) ·
[docs/THEMING.md](docs/THEMING.md).

## Project layout

```
lib/
  main.dart, app.dart
  core/theme/          # Material 3 themes + persisted ThemeMode
  core/monetization/   # Phase 3 seam: Entitlements interface + stub
  data/                # Question model (v1 mirror) + bank loading/validation
  features/
    domains/           # section picker
    quiz/              # session state + question screens
    results/           # score, breakdown, miss review
    settings/          # theme mode, about
assets/banks/          # engine-generated question banks
tools/generate_banks.py
```
