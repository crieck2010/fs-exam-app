# FS Exam Prep — Android Test Checklist (v0.4.1)

Test on your phone after installing the APK. Check off what works, note what doesn't.

## Install
- [ ] APK downloads and installs (allow "install unknown apps" for your browser/files app)
- [ ] App icon shows the total-station/checkmark icon (not the default Flutter icon)
- [ ] No "DEBUG" banner in the top-right corner

## First launch
- [ ] Home screen loads with the 7 domain cards
- [ ] Question-count slider moves and shows a number
- [ ] Start quiz button begins a quiz with your selected domains

## Quiz flow
- [ ] Questions show 4 choices, tapping one locks the answer
- [ ] Correct/incorrect feedback appears immediately with the explanation
- [ ] Confidence buttons (Guessed / Pretty sure / Knew it) appear after answering
- [ ] Quiz finishes → results screen with score and per-domain breakdown
- [ ] Retake and "drill misses" buttons work

## Daily loop
- [ ] Question of the day appears on the home screen
- [ ] Answering it increments your streak
- [ ] Due-review queue shows previously missed questions

## Settings
- [ ] Theme switcher: Light / Dark / System all apply
- [ ] Notification toggles exist (QOTD 8 AM, streak saver 8 PM, weekly report Monday)
- [ ] Exam date picker saves a date; home screen shows the countdown
- [ ] Weekly report screen opens with focus areas and strengths

## Report back
For anything broken, note: what you tapped, what you expected, what happened instead.
